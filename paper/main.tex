\title{Is It the Game or the Agent?\\
       Measuring What a Game Hides and Testing Whether Hidden Information Explains a Plateau}
\author{Anonymous submission}
\date{}

\begin{abstract}
A reinforcement learning agent stops improving against a fixed reference in an
imperfect-information game. Is the game hiding information the agent needs, or is the agent failing
to use what it already sees? These call for different experiments, and a win rate cannot tell them
apart. We build an instrument that can. First, we measure how much each game hides: at each
decision we count the game histories still possible from the acting player's observation and take
the base-two logarithm, a quantity we call \emph{support bits}. It upper-bounds the player's
uncertainty but says nothing about whether the hidden state would improve play.
Across 88 game configurations, every atlas entry records how it was obtained, and independent
bounds catch three measurement failures, one in our own control. Of the 18 measured two-player card
games, only one exceeds the case study's 30.1 support bits. Second, we test whether hidden information explains an agent's
plateau, by adding the hidden state to the learner's observation and retraining. In eleven games small
enough to solve, the exact ceilings give what that state is \emph{worth} for a stated opponent
policy, seeded runs measure how much the tested learners \emph{bank}, and a placebo arm prices the
wider observation. The probe fires in every one, with
gains of $0.22$ to $1.07$, while the placebo stays at the baseline. Applied unchanged to a twelfth game too large to solve, the oracle arm shows no detectable gain
over the baseline arm: $-0.25$ points over twelve seeds, interval $[-1.70, +1.20]$, and $-0.23$
below the placebo arm, ruling out gains above about $1.2$ points. The diagnosis is concrete: raw hidden-state access is not a large missing ingredient for this
learner and reference. More broadly, the instrument separates what a game hides, what that
information is worth, what a learner banks, and when the measurement itself has failed.
\end{abstract}

\section{Introduction}

Agents in imperfect-information games are graded against references that cannot bear the weight.
Random play yields numbers near 99 percent that barely move, self-play yields numbers near 50
percent by construction, and a pool of past checkpoints moves as the agent moves. Fixing the
reference is the obvious repair, and two questions survive it.

\textbf{How much does this game hide?} Games are chosen by reputation. Poker is hard, Hanabi is
cooperative, and Stratego is big. The quantity that unites them is rarely computed, so comparative
claims about difficulty rest on tradition.

\textbf{What is the plateau made of?} A learner that stops improving is stuck either because it
cannot see enough, or because it can and fails to exploit what it sees. The two diagnoses call for
different experiments, and one win rate cannot choose between them.

This paper's claim is one sentence. What a game hides, what that hiding is worth, and what a
learner banks of it are three different quantities, routinely reported as one. We give an
instrument that separates them.

We answer the first question by measurement and the second by decomposition, and the two belong
together. Without the atlas, a plateau invites the excuse that the game hides too much; without the
decomposition, the atlas is a table nobody acts on. Section~\ref{sec:method} defines the instrument and Section~\ref{sec:results} reports what it
found. We validate it first on eleven games small enough to solve, where exact ceilings let us
compute worth and detect impossible arm results, then run the same protocol unchanged on a twelfth
game far too large to solve.

\section{Related work}
\label{sec:related}

Our contribution is a validation design that connects domain measurement to plateau diagnosis:
every atlas entry records how it was obtained, independent bounds make silent instrument failures
visible, and exact ceilings validate a three-arm diagnostic before the same protocol runs where
those ceilings cannot be computed. Measurement work asks whether a test measures the construct it
names \citep{measurementfairness}, and benchmark critiques ask whether narrow coverage supports
broad claims \citep{wholeworld}. Prior game research measures related information-set structure
\citep{pimc,rbccomplexity,ggpii}, and privileged-state interventions are standard
\citep{policyinference,ismcts}. The individual quantities are not new; their provenance-aware
connection and validation sequence are.

\section{Method}
\label{sec:method}

\subsection{Measuring what a game hides}
\label{sec:m-atlas}

At any decision, some complete histories of the game remain consistent with everything the acting
player has seen, and hidden information is $\log_2$ of how many. Write $o$ for what the acting
player observes, $I(o)$ for that set of consistent histories, and $Z$ for the hidden state. Fix an opponent policy $\pi$ and let $V^\star_\pi(\cdot)$
be the best expected return achievable against it from a given observation. Then
%
\begin{align}
  b(o) &\;=\; \log_2 |I(o)| &&\text{support bits, what we measure,}
  \label{eq:bits}\\
  H(Z \mid O = o) &\;\le\; b(o) &&\text{with equality only if the posterior is uniform,}
  \label{eq:bound}\\
  \mathrm{worth}(\pi) &\;=\; V^\star_\pi(O, Z) - V^\star_\pi(O) &&\text{what the hidden state is
  worth.}
  \label{eq:worth}
\end{align}
%
Equation~\eqref{eq:bound} is why we keep the three apart. Support bits weight every possible
history equally, so they bound a player's real uncertainty and meet it only when every history is
equally likely: a player who knows the opponent almost always holds one hand is nearly certain,
even with a thousand hands still possible. Worth is further removed again, since
Equation~\eqref{eq:worth} can be zero while $b(o)$ is large when many hidden hands call for the
same move. We compute worth exactly wherever an optimum is available.

We report the mean support bits over every distinct information state in the tree, pooled across
both seats. Every state counts once, however often play reaches it, so a game with rare huge
information sets and common small ones reads higher than a player would feel. Counting states
equally needs no policy; weighting them by how often play reaches them would make the number
describe the policy as much as the game.

We compute support bits three ways and always report which. \textbf{Exact} enumeration walks the
tree and groups histories by information state. Enumeration returns the true value, and we can
afford it on 11 of our 88 rows.

\textbf{Closed form} counts the ways the hidden hands could have been dealt. If one opponent holds
$k$ cards drawn from the $u$ the player cannot see, that count is $\log_2\binom{u}{k}$. A full
table needs the multinomial instead, because it matters which opponent holds which cards. The
closed form is exact arithmetic for the deal, but it counts hands only and ignores what the face-up
cards already rule out, so it is an upper bound rather than an estimate. Leduc measures that gap at
2.01 bits under exact enumeration and 2.30 under the closed form. One row does not establish that
the gap is small in games with richer public histories, and we do not claim it does.

\textbf{Resampling} draws worlds consistent with the information state and counts the distinct
ones, censored at the sample count. Resampling can fail silently when its samples saturate or
collapse, so every resampled value must carry its censoring and diversity diagnostics.

The catalog spans 79 games from OpenSpiel \citep{openspiel}, the only engine here exposing
information-state strings and world resampling, and 9 from RLCard \citep{rlcard}. Gin Rummy is
measured by both and agrees at 30.1 bits, which cross-checks the closed form across libraries.

\subsection{Diagnosing a plateau: three probes}
\label{sec:m-probes}

The atlas says what a domain can hide. It cannot say whether a given agent is limited by that, and
the rest of the paper is about telling those apart. Our large case reuses the setting of a recent
study of lightweight card-game agents \citep{goldstandard}, which grades against a fixed rule-based
reference that never trains. The reference plays 600 games in about two minutes, and PettingZoo
\citep{pettingzoo} supplies the environment API. The three contrasts apply across games, but each
game still needs a verified oracle observation and a matched placebo.

\paragraph{The subset argument, which needs no experiment.} Our reference reads two of the
learner's four observation planes, so it sees a strict subset of what the learner sees, and it
scores about 50 percent against itself. Parity is therefore well defined, and any policy reaching
it is a function of information the learner already receives. This transfers to any domain where
the reference restricts the learner.

\paragraph{Probe 1: architecture sensitivity.} Train the identical recipe with different encoders,
as in the architecture sweep of \citet{goldstandard}. This varies inductive bias and compute
together, so it is a sensitivity check rather than a controlled capacity sweep. The controlled
version folds information states into a fixed number of buckets, and it is in
Appendix~\ref{app:capacity}.

\paragraph{Probe 2: the oracle-search gap.} Run a determinized search \citep{pimc,ismcts} graded
fairly, then as an oracle handed the true hidden cards, following \citet{goldstandard}. The gap is
not a clean value of information, because oracle access removes strategy fusion
\citep{strategyfusion,rebel} as well as uncertainty. The gap therefore bounds the benefit available
inside this search protocol, not the decision-theoretic value of revealing the state. We reserve
the word \emph{worth} for the exact quantity defined below.

\paragraph{Probe 3: the oracle-observation learner.} Retrain the identical recipe with the hidden
state appended to the observation and change nothing else, putting the question to the learner
rather than to a search agent. A third arm reads the result, because widening an observation adds
inputs the network must learn to ignore: a \emph{placebo} plane of the same shape and sparsity,
holding ten cards this player cannot see, drawn independently of the opponent's hand. PettingZoo's
\texttt{opponents\_hand\_visible} flag does \emph{not} supply the opponent's hand, so we built our
own plane and verified it against engine ground truth (Appendix~\ref{app:apparatus}).

\subsection{Decomposing a plateau: worth, banked and capture}
\label{sec:decomp}

Where exact optima are available, the probe decomposes the plateau into worth, banked and capture.
Worth is the best return achievable with the hidden state minus the best achievable without it.
Banked is the oracle arm's observed return minus the baseline arm's observed return, and capture is
banked divided by worth. Both ceilings use the same fixed opponent policy and differ only in
whether the learner sees the hidden state, so worth is exact for that evaluation setting rather
than for the game in the abstract. Unequal gaps between the trained arms and their own ceilings can
place capture above or below one. Write $g_b$ for how far the baseline arm sits below its own ceiling, and $g_o$ for the
same quantity in the oracle arm. Then banked, worth and those two gaps are not independent:
%
\begin{equation}
\text{banked} \;=\; \text{worth} \;+\; g_b \;-\; g_o .
\label{eq:identity}
\end{equation}
%
That equation is an identity, not a finding. It follows from the definitions in one line, and our
runs satisfy it to machine precision. Dividing by worth gives the consequence: capture exceeds $1$
exactly when $g_b > g_o$. The identity does not explain why the gaps differ or supply a corrected
value.

\paragraph{In this atlas, the extra bits come from extra players.} The three and four-handed family

\subsection{Catching silent measurement failures}
\label{sec:r-failures}

A measurement that fails loudly is not dangerous. Three of ours failed quietly, returning ordinary
looking numbers, and an independent bound caught all three. Resampling is what a practitioner
reaches for when a game is too large to enumerate, and here it fails both ways.

\textbf{Saturation.} Hearts, Euchre and contract bridge each returned exactly 6.32 bits, which is
$\log_2 80$, the sample count, with 100 percent of sampled points censored. The estimator had
exhausted its samples rather than the possible worlds, and the closed form puts Hearts at 56.2,
nearly nine times higher.

\textbf{Degeneracy} is the worse failure, because it looks like a clean result. Every Gin Rummy
configuration returns \emph{0.00} bits with zero censoring, since the engine's resampler hands back
the same world on every draw, and a survey trusting that column would file a 30-bit game beside
Connect Four. Neither is visible without a second method to disagree with, which is the practical
case for recording in every row how the number was obtained.

\paragraph{The check also catches our own control.} The two above are failures of an estimator we
did not write; the same bound caught one in a control we did. In Liar's dice with two dice per
player, the placebo arm scored $0.67$ above its own exact ceiling, which no policy can do. The
cause is the mechanism the placebo exists to avoid. Drawn once per deal from a space large enough
that each draw is nearly unique, the fake plane stopped being noise and became a fingerprint of the
deal, which a tabular learner could key on to recover what the plane was built to withhold. We
report the game as rejected rather than fixing it after the fact (Appendix~\ref{app:reject}).

All three were caught the same way. The alarm was never that a number looked wrong, but that it
broke a bound we could compute independently.

\subsection{The decomposition across eleven games}
\label{sec:r-decomp}

  \centering \small
  \input{../tables/app_axis.tex}
  \caption{The decomposition over eleven games spanning 1.00 to 3.67 bits, eight seeds each. Worth
  is the exact gap between the two ceilings for this opponent policy. Banked is the oracle arm minus
  the baseline arm, and capture is banked divided by worth. Equation~\eqref{eq:identity} shows how

  \label{tab:axis}
\end{table}

We swept training budgets from 25{,}000 to 1{,}600{,}000 episodes, a sixty-fourfold range. Worth is
constant to three decimals in both games (Appendix~\ref{app:budget}). Capture moves with the budget
instead, rising from $56$ to $79$ percent in Leduc Hold'em and moving unevenly in Kuhn. Within a
stated opponent policy, the plateau therefore separates into exact worth set by the evaluation
setting and banked measured from the learner. A win rate cannot make that distinction.

Across the eleven decomposed games in Table~\ref{tab:axis}, placebo-minus-baseline widening stays
inside seed noise in every row. These runs therefore give no evidence that the wider input hides a
real gain, which is the reading a placebo exists to rule out. That claim is weaker than saying
widening is free, and it is the one the runs support.

\paragraph{Capture above one hundred percent.} Seven of the eleven games report capture above $100$
percent. That is impossible only if capture is read as a literal fraction of available worth, and
Equation~\eqref{eq:identity} shows why that reading fails. Such values are not algebraic
contradictions. They occur exactly when the baseline arm finishes further below its ceiling than
the oracle arm finishes below its own. The seven dice configurations satisfy that inequality, while
the four poker variants do not. Which games satisfy the inequality and by how much remains
empirical. The identity establishes only the relationship. It does not show that revealing the
hidden state caused either arm to be easier to learn.

  \centering
  \includegraphics[width=0.88\linewidth]{fig_mechanism.pdf}
  \caption{One bar per game for $g_b - g_o$, with capture at the end of each. Equation

Capture is therefore sensitive to unequal ceiling gaps. In the four poker variants, the oracle arm
finishes further below its ceiling and capture lies between $73$ and $78$ percent. In the seven dice
variants, the baseline arm finishes further below and capture exceeds $100$ percent. These are observed gap differences, not evidence that either arm was causally easier to learn. We
report them without a corrected capture value because the identity supplies no such correction.
None of this reaches the case-study null in Section~\ref{sec:r-case}, which never divides by
worth.

Probe 1 finds a plain MLP averaging 25.5 percent over four seeds and a self-attention encoder 25.7,
with all eight seeds inside 21.2 to 30.0. No tested encoder improves mean performance. Attention
changes the variance at roughly twelve times the wall-clock cost.

Probe 2 finds fair search reaching 10.3 percent at 10 rollouts and 25.6 at 120, against 40.7 and
85.3 for the oracle variant on identical budgets.

Probe 3 is the one that answers the question. Handed the opponent's hand outright, the learner
reaches $26.79$ percent across twelve seeds against a $27.04$ baseline. The difference is $-0.25$
points, with a 95 percent interval of $[-1.70, +1.20]$ (Figure~\ref{fig:probes}). An earlier
four-seed version had an interval of $[-4.5, +2.7]$, which excluded almost nothing.

The placebo arm scores $27.02$ percent, $-0.02$ points from baseline with an interval of
$[-1.51, +1.47]$, so we find no evidence that the cost of the wider input hides a real gain. The
contrast that isolates the information is oracle against placebo, which holds the input shape fixed
and changes only whether the plane is true: $-0.23$ points, interval $[-1.57, +1.11]$.
Table~\ref{tab:probes} carries all three.

Twelve seeds rule out gains above about $1.2$ points. That is about one twentieth of the distance
from this agent's $27$ percent to the parity its reference defines. Smaller gains remain possible,
and we do not claim the effect is exactly zero.

\paragraph{Does the probe work at all?} A null is worth nothing without evidence the instrument can
fire. We ran the identical probe on every OpenSpiel game small enough for counterfactual regret
minimisation to supply a true optimum, with a tabular learner and with a neural learner reading a
fixed-width tensor, as the case-study learner does. It fires in every tested configuration where
the hidden state is present, by margins of $0.22$ to $1.07$ in expected return. The placebo lands
on the baseline every time. Those margins show the instrument works on games of this size. They do
not prove it fires wherever information exists. On the large case study, the same construction
shows no detectable gain (Figure~\ref{fig:sensitivity}).

\section{Discussion}

We entered with the hypothesis that this agent had stalled because the game hid too much from it.
The three results above narrow that explanation together. The game does hide substantial
information, a parity-achieving policy needs only what the learner already receives, and handing
over the rest changes nothing we can detect above about $1.2$ points.

The result is actionable and bounded. It does not show that the hidden hand has zero worth or that
belief modelling cannot help. The raw channel is an observation intervention, and a structured
encoding of the same information might still produce a smaller gain.

\paragraph{Scope.} The large-case result is for one learner, one recipe and one fixed reference, so
it tests the protocol rather than establishing a domain-general cause of plateaus.
Appendix~\ref{app:scope} lists what else the evidence does not carry, including capacity lost
during training \citep{capacityloss}.

\section{Conclusion}

One win rate cannot separate what a game hides, what that information is worth, and what a learner
banks. The atlas measures the first across 88 game configurations while recording the provenance of
every value, and independent bounds catch three instrument failures, one in our own apparatus.
Exact ceilings then validate the three-arm diagnostic across eleven solvable games. Applied
unchanged to the large case study, it rules out gains above about $1.2$ points from the raw
hidden-hand channel, so raw hidden-state access is not a large missing ingredient for this learner
and reference. The protocol turns an informal explanation for a plateau into a checkable
measurement, and detects when its own instruments fail.

\section{Reproduction}
\label{app:repro}

Every table and figure is generated from files in \texttt{data/} by a script in \texttt{scripts/}.
Nothing in this paper is typed by hand. The atlas comes from \texttt{scripts/atlas\_tables.py},
the probe tables from \texttt{scripts/probe\_tables.py}, and the appendix tables from
\texttt{scripts/make\_appendix.py}. Regenerating them from a clean checkout reproduces the paper.

Ceilings are exact rather than estimated. The baseline ceiling is the best response to the opponent
policy, computed with OpenSpiel's \texttt{BestResponsePolicy}. The oracle ceiling is a memoised
expectimax over the same game with the hidden state revealed. Both are closed-form values of the
game, so they carry no seed noise and no confidence interval.

Probe runs use eight seeds per game unless the table says otherwise. The Gin Rummy arms use twelve.
Tabular runs use \texttt{data/configs/}; neural runs use a fixed-width tensor observation and
policy gradient, matching the encoder the Gin Rummy learner uses.

\section{What the probes measure}
\label{app:apparatus}

The placebo arm is the part of the design most easily got wrong, so it is worth stating exactly.
The placebo plane has the same shape and the same sparsity as the oracle plane. It holds ten cards
this player cannot see, drawn independently of the opponent's actual hand, and it is resampled once
per deal rather than once per decision. Resampling per decision would not leak, because a learner could average that noise away. But it
would give the placebo arm a different input distribution than the oracle arm sees. One draw per deal keeps the two arms matched.

An early version of the placebo drew from a pool of the wrong size. The plane was therefore not
matched in cardinality to the oracle plane, and the arm priced something other than the widening.
We fixed the pool and re-ran every affected game, so the numbers reported here are from the
re-run.

We also verified that the oracle plane is what we say it is. PettingZoo's
\texttt{opponents\_hand\_visible} flag does not supply the opponent's hand. It exposes an
``unknown cards'' plane, which holds 41 cards on a fresh deal against the opponent's 10, so a
learner reading it cannot recover the hand. We built our own plane and checked it against engine
ground truth at 1,200 decision points. Each curriculum opponent's input is trimmed to its own
width, so the extra plane reaches the learner and nobody else.

\section{The decomposition across eleven games}
\label{app:axis}

The per-game numbers are in Table~\ref{tab:axis} in the main text. This section records how they
were produced and what each column can carry.

Worth is the oracle ceiling minus the baseline ceiling. Both are exact for the stated opponent
policy, so worth alone carries no seed noise. The eight seeds per game reach banked and widening
directly, and reach capture through banked. Banked
is what the learner gains from the hidden state, measured as the oracle arm minus the baseline arm.
Capture is banked over worth, and widening is the placebo arm minus the baseline arm.

The eleven games are not eleven independent domains. Seven are Liar's dice at different die sizes
and three are Leduc variants, so the spread of bits is wider than the spread of game structure.
We chose that deliberately. Holding the game fixed and moving one parameter is what lets worth be
compared across rows at all. It also means the seven-to-four split in Section~\ref{app:mechanism}
tracks two game families, not seven independent confirmations, and we do not read it as such.

\section{Worth does not move with the training budget}
\label{app:budget}

If worth were a property of the learner, it would drift as the learner trained longer. It does not.
Table~\ref{tab:app-budget} runs the decomposition at 25,000 to 1,600,000 episodes, a
sixty-four-fold range. Worth is constant to three decimals at every budget in both games, which is
what an exact property of the evaluated game and opponent should do. Capture moves instead,
rising from 56 to 79 percent in Leduc Hold'em. Kuhn poker is the useful contrast. Its capture dips to 83 percent at 400,000 episodes, then
returns to 97 at 1,600,000. The game is small enough that the learner is already near its ceiling
at the smallest budget, so the middle budgets show seed noise rather than a trend. We report it
rather than smoothing it away.

\section{What a capacity-bound plateau looks like}
\label{app:capacity}

The capacity probe asks a different question. Not what the game hides, but whether the learner can
tell enough situations apart. We fold information states into a fixed number of buckets and
sweep that number. A learner limited by state resolution improves as the buckets increase, then stops when it runs
out of them.

Leduc Hold'em is the clean case. Exploitability falls from 5.58 at two buckets to 1.55 with exact
states, and the curve is monotone over the last three points. A state-resolution bottleneck would look like that, on a single sweep
without replication. Kuhn poker and Liar's dice are flat across the whole sweep, because both are small
enough that two buckets already separate what matters. Dark hex on a two by two board is solved, so every arm
reads zero. The game sits in the table as a control. The instrument should return zero when there is
genuinely nothing to find, and it does.

\section{Choosing a reference when no expert exists}

Our case study had a hand-codable reference. Most domains do not, and the choice of what to grade
against decides what a win rate can mean, so it is worth stating what we would do instead.

The best substitute is a reference built on a strict subset of the learner's observation. The learner can then reach parity by construction, which is what let our subset argument work
without an experiment. Failing that, freeze the strongest heuristic available and report where it saturates, so a reader
knows where the scale stops being informative. A frozen pool with a fixed
Elo anchor is next, and a snapshotted checkpoint promoted to reference and never updated is last,
because it moves with whatever produced it.

Equilibrium baselines \citep{cfr,nfsp,deepcfr} give an absolute reference wherever the game is
small enough to solve, and that is what we use for the eleven decomposed games. The reason we
cannot use one on Gin Rummy is the reason the case study needs a reference at all.

\section{What the evidence does not carry}
\label{app:scope}

The large application has one learner, one recipe and one fixed reference. It tests the protocol
rather than establishing a domain-general cause of plateaus, and a second frozen reference would
be the first thing to add.

The eleven exactly solved games calibrate the instrument, but seven are Liar's dice variants and
four are poker, so they are not eleven independent confirmations. Wider coverage in bits did not
buy wider coverage in structure.

The oracle-search gap is confounded with strategy fusion, so it bounds the benefit available inside
that search protocol rather than the decision-theoretic value of revealing the state. The
architecture probe varies inductive bias and compute together, and neither it nor the bucket sweep
tests capacity a network loses during training \citep{capacityloss}. Closed forms count hands and
ignore what public cards rule out. Support bits describe the game rather than the difficulty of
learning it: we claim the two are routinely conflated, not that they are unrelated.

\section{The rejected game}
\label{app:reject}

Every arm is graded against a ceiling that is a closed-form property of the game. An arm scoring
above its own ceiling is therefore impossible, not merely surprising. We check it automatically, and
one game of twelve fails.

In \texttt{liars\_dice(numdice=2,dice\_sides=3)} the placebo arm returns $0.738$ against a ceiling
of $0.062$, a violation of $0.68$, consistent across all eight seeds. The placebo plane is drawn
once per deal so that its input distribution matches the oracle plane's. With two dice the space it is drawn
from is large enough that each draw is close to unique. The plane then acts as an identifier. The
learner keys on it, splits states that should share a policy, and recovers the hidden information
indirectly. The recorded state count shows the split, at 4046 visited states
against the baseline's 3046.

The one-die games avoid this failure because their placebo alphabet contains only three to six
values, far too few to fingerprint a deal. The fix is to match the placebo's cardinality to
the hidden state rather than to its shape, which is a rerun we did not have time for. We exclude the
game from every table rather than report it, and the rejection rule is in
\texttt{scripts/make\_appendix.py} so no future run can enter a table unannounced.

\section{Capture above one hundred percent}
\label{app:mechanism}

Section~\ref{app:axis} reports capture above $100$ percent in seven games, and the body derives
why.
This section gives the derivation in full and the per-game numbers behind it.

\paragraph{The identity.} Let $c_b$ and $c_o$ be the exact baseline and oracle ceilings, and let
$r_b$ and $r_o$ be what the trained arms actually score. Worth is $c_o - c_b$ and banked is
$r_o - r_b$. Each arm's gap below its own ceiling is $g_b = c_b - r_b$ and $g_o = c_o - r_o$.
Substituting gives
%
\[
g_b - g_o \;=\; (c_b - r_b) - (c_o - r_o) \;=\; (r_o - r_b) - (c_o - c_b)
           \;=\; \text{banked} - \text{worth},
\]
%
which rearranges to Equation~\eqref{eq:identity}. Our runs satisfy it with a maximum residual of
$1.1 \times 10^{-16}$, which is floating point and nothing else.

Two things follow from that. First, capture exceeds $1$ if and only if $g_b > g_o$. Second, and this matters
for how the result is read, that equivalence is guaranteed by the definitions. Counting how many
games obey it would measure nothing. An earlier draft of this paper reported the count as though it
were evidence, and it is not.

\paragraph{What is empirical.} The identity says the two quantities move together. It does not say
which side of $100$ percent any game lands on, or by how much. Those are facts about our runs, and
Table~\ref{tab:app-gaps} reports them. The dice variants sit close to their oracle ceilings, with
$g_o$ between $0.000$ and $0.007$, because with the opponent's die revealed the game is nearly
solved. The poker variants sit far from theirs, with $g_o$ between $0.377$ and $0.394$, because the
oracle ceiling is much higher and the learner does not reach it. The split into two families is the
result; the sign agreement is arithmetic.

  \centering \small
  \input{../tables/app_gaps.tex}
  \caption{How far each arm sits below its own exact ceiling, sorted by capture. The difference
  column is $g_b - g_o$, which Equation~\eqref{eq:identity} makes equal to banked minus worth. It

  \label{tab:app-gaps}
\end{table}

\paragraph{What we can rule out.} One reading is a bug in the oracle ceiling. If it were too low,
capture would exceed $100$ percent everywhere, and it does not. The four poker variants run the
same ceiling code and land below. A second reading is that the effect is too small to trust. Per
game the gap difference is $0.8$ to $2.3$ times the seed spread of the banked column, so no single
game settles it on its own. We report the two-family pattern rather than a test, because eleven
related configurations do not supply eleven independent trials.
