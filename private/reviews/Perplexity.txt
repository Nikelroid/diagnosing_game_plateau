THE MISSING CLAIM  
The paper’s own data supports a sharper methodological claim than it currently makes: **a placebo is not merely a nuisance control for input width; under a ceiling check, it is an adversarial audit of whether an observational intervention leaks episode identity.** The rejected two-dice game is the evidence. It shows a superficially matched control can improve performance beyond a known ceiling because persistent random features create a de facto state key. That result should appear in the body as a design rule: any privileged-information control with per-episode randomization requires a leakage/ceiling audit before interpreting an oracle result.

THE PAPER I WOULD WRITE  
**Title:** *When Privileged Information Fails to Help: Placebo-Controlled Diagnostics for Partially Observable RL*

**One claim:** A null result from privileged observations is interpretable only when the intervention is matched to a validated placebo and evaluated against a fixed reference; otherwise width effects and identifier leakage can masquerade as information effects.

**Three carrying results:**  
1. In Gin Rummy, raw access to the opponent hand produces no detectable improvement over a matched fake-hand control, with precision sufficient to exclude gains above a stated threshold.  
2. In solvable games, the same oracle intervention reliably fires where hidden state is usable, across tabular and neural learners.  
3. A ceiling-violating placebo in Liar’s Dice demonstrates that a visually matched control can leak per-deal identity, motivating a formal validity check.

Support bits become a secondary benchmark-description result, and “capture” is retained only after its estimand is repaired.

THE ONE EXPERIMENT  
Run a four-arm Gin Rummy study with equal parameter count, compute, curriculum, and 12–24 independent training seeds: baseline; raw true opponent hand; a **structured true-hand feature set** encoding opponent rank/suit counts and meld/deadwood-relevant summaries; and an identically structured fake-hand placebo. Evaluate all against the same frozen expert over the same per-seed match count.

A structured-oracle minus structured-placebo gain whose 95% interval excludes zero—and preferably exceeds the predeclared practical threshold of 1.3 percentage points—would change the paper’s claim from “the raw channel did not help” to “the information is usable, but representation accessibility was the bottleneck.” A null with comparable precision would make the current narrow Gin Rummy conclusion materially stronger. Cost: roughly 48 training runs at the present 12-seed standard, plus feature implementation and leakage verification; compute is modest relative to the time needed to implement and audit features.
